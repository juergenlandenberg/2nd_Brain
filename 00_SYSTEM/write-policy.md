# 2ndB Write Policy

The 2nd Brain uses one active writer per note: Erna.

Agents may:
- read published 2ndB content;
- cite it in work;
- report stale or incorrect information;
- submit a structured change proposal.

Agents may not:
- edit Drive notes directly;
- edit the local mirror as an authoritative source;
- copy Gmail or private material into 2ndB;
- publish credentials or operational secrets.

Every accepted change must retain source, reason, date, and affected links. Conflicts remain visible until Erna resolves them.
