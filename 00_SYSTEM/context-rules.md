# Context Rules

## Read order
1. `INDEX.md`
2. The relevant `XX_Wiki/` page(s)
3. The linked entry in `30_SOURCES/`
4. The original file in `10_RAW/` or `40_ATTACHMENTS/` when verification is needed
5. External research only when the vault is insufficient or the user requests current information

## Scope
Open the smallest number of files needed. Follow at most one link hop automatically; expand only when evidence is incomplete or contradictory.

## Evidence labels
Use: `Fact`, `Source-reported`, `Inference`, `Open question`, or `Conflict` where useful.

## Updates
Do not edit RAW. Update WIKI only when the new source adds, corrects or materially qualifies knowledge. Keep the old claim visible when a conflict is unresolved.

## Security
Never store credentials, OAuth tokens, API keys, passwords, private keys or sensitive personal data unless explicitly approved and protected outside the vault. Redact secrets as `[REDACTED]`.
