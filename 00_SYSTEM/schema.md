# Note Schema

Every curated WIKI note should use, where applicable:

```yaml
---
title: ""
type: concept | research | project | decision | operation | agent | source
tags: []
status: draft | active | superseded | archived
created: YYYY-MM-DD
updated: YYYY-MM-DD
sources: []
---
```

## Body guidance
- State the conclusion or purpose first.
- Separate facts, interpretation and open questions.
- Link related WIKI pages with Obsidian links.
- Name the source path or URL for material claims.
- Record supersession instead of silently deleting history.
