# Agent Access Policy — 2ndB

- **Erna is the sole administrator and writer** of the authoritative 2nd Brain.
- All other agents have read-only access to the published mirror and curated notes.
- Agents submit proposed changes, corrections, or new knowledge to Erna; they do not edit the authoritative Drive vault directly.
- Erna validates provenance, conflicts, secrets, and scope before publishing.
- Private Gmail, Calendar correspondence, attachments, tokens, credentials, and unrelated personal files are outside 2ndB.
- The local Hermes mirror is read-only for agents and contains only Hermes-relevant Markdown.

Workflow: agent reads → agent proposes/request changes → Erna validates → Erna writes/publishes → mirror is refreshed → agent receives result.
